# 우리 반 퀴즈 게임 키트

구글 시트에 문제를 적으면, 게임 3종(원펀맨 · 마리오 · 얼티밋 배틀)이 그 문제로 진행되고
점수가 다시 시트에 기록됩니다. Claude Code에게 말로 부탁해서 내 시트에 연결하고 인터넷에 배포합니다.

```
게임 (Vercel)  ──문제 요청──▶  Apps Script 웹 앱  ──▶  구글 시트 Questions 탭
               ◀──점수 저장──                     ──▶  구글 시트 Results 탭
```

> 게임 3종은 원작자의 허락을 받아 연수용으로 사용합니다.

## 1. 구글 시트 준비 (브라우저)
1. 새 구글 시트를 만들고 탭 이름을 `Questions`, `Results`로 만듭니다.
2. `sheet-template/Questions.csv`, `sheet-template/Results.csv`를 각 탭에 가져옵니다.
   ([파일] → [가져오기] → [업로드] → "현재 시트 바꾸기")
3. [확장 프로그램] → [Apps Script]에 `apps-script/Code.gs` 내용을 붙여 넣고 저장합니다.
4. [배포] → [새 배포] → 톱니바퀴에서 **웹 앱** 선택
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 권한 승인 화면에서 "확인되지 않은 앱"이 나오면 [고급] → [(프로젝트 이름)(으)로 이동]을 누릅니다.
6. **웹 앱 URL**(`/exec`로 끝나는 주소)을 복사합니다.
7. 새 탭에서 `복사한주소?code=TECH01`을 열어 `"status":"success"`가 보이면 성공입니다.

## 2. Claude Code로 연결하고 배포하기 (터미널)
이 폴더에서 `claude`를 실행하고 아래처럼 말해 보세요.

1. `시작하자. 내 웹 앱 주소는 https://script.google.com/macros/s/…/exec 야.`
2. `로컬에서 실행해줘.` → 브라우저에서 참여 코드 `TECH01`로 한 판 → 시트 Results 탭 확인
3. `GitHub에 내 저장소 만들어서 올려줘.`
4. `Vercel로 배포해줘.` → 나온 `https://….vercel.app` 주소를 친구에게 공유!
5. `제목을 ○○반 퀴즈로 바꾸고 다시 배포해줘.`

## 3. 문제 바꾸기
Questions 탭에 줄을 추가하면 바로 반영됩니다(다시 배포할 필요 없음).
- `code`: 참여 코드. 같은 코드끼리 한 세트입니다(예: `MATH5`).
- `answer`: 보기(option1~4) 중 하나와 **글자까지 똑같이** 적어야 합니다.
- 한 코드에 **10문제 이상** 넣는 것을 권장합니다(게임마다 10문제를 무작위로 뽑습니다).
